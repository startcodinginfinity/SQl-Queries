# SQL Practice

A structured SQL practice repository designed to build strong SQL skills for software engineering, backend, data engineering, and technical interviews.

## Topics Covered

* SELECT, WHERE, ORDER BY
* GROUP BY and HAVING
* Aggregate functions
* INNER, LEFT, RIGHT, and SELF JOINs
* Subqueries
* CTEs
* Window functions
* CASE statements
* Date and string functions
* Conditional aggregation
* Database design
* Constraints and indexes
* Query optimization
* Real-world SQL problems
* SQL interview questions
